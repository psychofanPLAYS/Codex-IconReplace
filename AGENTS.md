# Antigravity Agent Guidelines for Codex-IconReplace

## 1. Versioning Rule
Every time a major feature or significant structural change is successfully deployed, the application version number must be incremented by thousandths increments (e.g., `0.1.0` -> `0.1.015`). This version string must be updated directly in the UI (e.g., `app/src/gui.py`) before pushing the final release.
